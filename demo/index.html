Multi-factor authentication

Concept walkthrough

MFA combines something you know (master password) with something you have (authenticator app).

  1. Enter username and master password.
  2. Open authenticator app enrolled using a QR code.
  3. Enter the current six-digit TOTP.
  4. If authenticator access is lost, use one unused recovery code.
This public preview does not issue QR codes or validate OTPs. Perform real MFA only in the local application.

Account recovery policy

  • Forgot master password: reset with a valid unused recovery code.
  • Signed in: re-authenticate with master password and TOTP to rotate recovery codes or change password.
  • Lost all credentials: destructive local account reset and fresh setup.
